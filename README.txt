MAHENDER JEWELLERS PRO — OFFLINE PWA

Included:
- Gold and Silver multi-item billing
- Per-item tunch calculation (tunch is stored internally and hidden from customer copy)
- Gross, stone and net weight; rate per 10g; purity; wastage; labour fixed/per gram/percentage; other charges; hallmark/HUID note
- Customer book with mobile/address
- Customer khata with dated bill debit and payment credit entries
- Daily book with bill sales, customer receipts, cash-in and cash-out
- Customer bill with jewellery logo at top-right
- Print / Save as PDF and JPG export
- Local device storage and service-worker offline cache

INSTALL:
Upload index.html, manifest.webmanifest, sw.js, and logo.svg to the same folder on an HTTPS host.
Open the HTTPS URL in Chrome on Android, choose ⋮ > Install app / Add to Home screen.
Open once while online to cache the app; then it can be used offline.

DATA:
All app records are stored in this browser/device's localStorage. They do not automatically sync to another phone. Clearing browser/site data can erase records. Export/print/backup regularly. The JPG export uses browser SVG-to-canvas support; if unsupported, use Print > Save as PDF.
